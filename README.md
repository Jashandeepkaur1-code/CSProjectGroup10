## Project Description
This C# console application calculates BMI, evaluates blood pressure status, and displays patient information. The project includes two main files:

- Program.cs (main entry point)
- Patient.cs (patient class with BMI and BP methods)

## How to Run
Open the project in Visual Studio Community → Run using the green Start button.
